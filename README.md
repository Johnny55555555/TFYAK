## Вариант задания

**Тема работы:** Объявление массива символов с инициализацией строковой константой на языке C

**Примеры верных строк:**
```c
const char str[10] = "Hello World";
const char name[] = "Привет, мир!";
const char buffer[5] = "Test";
const char x[3] = "A";
```

## Контекстно-зависимые условия (семантические правила)

### Правило 1: Уникальность идентификаторов
Запрещается повторное объявление одного и того же идентификатора в одной области видимости.

| Пример | Ожидаемое сообщение |
|--------|---------------------|
| `const char str[10] = "Hello";`<br>`const char str[20] = "World";` | `Ошибка: идентификатор "str" уже объявлен ранее (строка 1)` |

### Правило 2: Совместимость типов
Тип инициализирующего значения должен соответствовать объявленному типу.

| Пример | Ожидаемое сообщение |
|--------|---------------------|
| `const char str[10] = 123;` | `Ошибка: тип значения не соответствует объявленному типу "char[]"` |

### Правило 3: Допустимые значения
Размер массива должен быть достаточен для хранения строки (включая нуль-терминатор).

| Пример | Ожидаемое сообщение |
|--------|---------------------|
| `const char str[3] = "Hello";` | `Ошибка: размер массива (3) недостаточен для строки "Hello" (требуется 6 байт, включая '\0')` |

## Структура AST

### Типы узлов AST

| Узел | Описание | Атрибуты |
|------|----------|----------|
| `ConstArrayDeclNode` | Объявление константного массива | `name`, `modifiers` |
| `CharArrayTypeNode` | Тип "массив символов" | `size`, `isAutoSize` |
| `StringLiteralNode` | Строковая константа | `value` |

## Инструкция по запуску

### Системные требования
- ОС: Windows 7/8/10/11
- .NET Framework 4.7.2 или выше
- Visual Studio 2019/2022 (для компиляции)

### Способ 1: Запуск из Visual Studio

1. Откройте файл решения `ТФЯК__1.sln` в Visual Studio
2. Нажмите клавишу **F5** или выберите меню **Отладка → Начать отладку**
3. Программа запустится в окне редактора кода

### Способ 2: Запуск из исполняемого файла

1. Откройте папку `bin\Debug\` или `bin\Release\`
2. Запустите файл `ТФЯК__1.exe`
3. При необходимости разрешите выполнение приложению
